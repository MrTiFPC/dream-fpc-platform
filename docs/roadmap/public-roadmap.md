# Public Roadmap

## Current Public Lane

- L2J Mobius Essence 09.1 Warg.
- Public FPC platform source.
- Public FPC Studio sidecar/control plane.
- Public Warg example FPC content.
- Mobius Warg integration config and schema material.

## Near-Term Work

- Assemble the final clean public export root from the staged Java, control-plane, content, and docs folders.
- Generate a minimal Mobius Warg patch kit from a clean baseline.
- Add a first-user walkthrough for creating one safe FPC in Warg.
- Add screenshots or short demo links after the public source shape is stable.

## Deferred Work

- RoseVain compatibility work.
- Classic compatibility work.
- Monster/FMC content.
- Wider Mobius Essence lane support.
- Wider host or all-game portability.

These are future directions, not a current guarantee or support promise.

## Non-Goals For The First Release

- Shipping a raw workspace dump.
- Shipping generated runtime folders or build output.
- Shipping NCSoft client files, geodata, or private/subscriber Mobius files.
- Claiming broad cross-game support before clean validation exists.
