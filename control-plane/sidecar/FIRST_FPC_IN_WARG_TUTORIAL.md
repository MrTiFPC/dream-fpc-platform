# First FPC In Warg

This tutorial is for the current narrow product scope only:

- target game: `L2J Mobius Essence 09.1 Warg`
- tool: `FPC Studio`
- goal: create one real first FPC without dev knowledge

## What You Will Make

You will create one safe first draft NPC in the live Warg lane, save the workspace, create the draft bundle, run the first proof if runtime is available, and then either keep it as a draft or move it into the current publish flow.

This tutorial does not try to cover:

- bigger cast packs
- variants or sequels
- advanced family workflow
- cross-game portability

## Before You Start

Make sure these are true:

- Studio is open at `/studio`
- the current runtime is the Warg runtime
- the `Create` tab is available
- you can see `L2J Mobius Essence 09.1 Warg (Live Runtime)` in the Mobius target selector

If the runtime is down, you can still finish the tutorial honestly. Studio will let you save and publish the draft without pretending live proof happened.

## The Exact Beginner Path

1. Open `Create`.
2. Find the `First FPC in Warg` card.
3. Click `Start Tutorial` from the mentor starter, or use the tutorial card to load the safe starter.
4. Confirm the starter lane is:
   - `Mentor Guide`
   - world: `Giran Mentor Desk`
   - host: `L2J Mobius Essence 09.1 Warg (Live Runtime)`
5. Click `Preview Exact Draft`.
6. Review the exact preview.
   - You should see a draft that already carries Warg-specific farm, gossip, continuity, and follow-through shaping.
7. Click `Save Project`.
   - This keeps the workspace so you can reopen it later in `Saved Projects`.
8. Click `Create Draft Bundle`.
   - This writes the first real draft bundle.
9. If live runtime proof is available, run the first proof step Studio recommends.
10. Choose the current safe outcome:
   - keep as draft
   - publish into the current Warg-first flow
11. Open `World Library` to find the first tutorial FPC again.

## What Good Looks Like

A good first result should feel:

- grounded
- useful
- socially human
- Warg-specific
- not robotic

For this narrow project, a good first reply is usually:

- aware of level, gear feel, healer need, or route truth
- willing to gossip or hedge rumors like a player
- able to remember help, ditching, flame, or shared wipes
- short enough to feel like game talk, not support-bot talk

## If Live Proof Is Available

Use the first proof lane Studio recommends.

Good proof means the draft can answer real Warg prompts like:

- where to farm with this level and gear
- whether the party can hold the lane
- how to compare a practical upgrade
- how to answer town gossip or PvP flame
- how to react when someone helped before or ditched before

## If Live Proof Is Not Available

Do not fake it.

Use the same tutorial flow, but stop honestly at:

- saved project
- created draft bundle
- draft publish or dev-review handoff

Studio is already designed to handle that path without pretending the proof succeeded.

## Where To Continue After The First Success

After the first tutorial run, use these next:

- `Saved Projects` to reopen the workspace
- `World Library` to inspect the created or published package
- `Warg Server-Life Tuning` to deepen farm, gear, gossip, healer, and memory behavior
- `Warg Scene + Continuity Follow-through` to deepen return behavior, second-contact scenes, and party judgment

## What Not To Do Yet

For the first run, do not widen scope too early.

Avoid:

- cross-game targeting
- big world packs
- multi-family branching
- over-editing before the first working draft exists

The current product promise is Warg-first. Get one real success first, then refine it.
