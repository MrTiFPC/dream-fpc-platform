# First FPC in Warg

This is the safe first no-dev tutorial for `L2J Mobius Essence 09.1 Warg`.

It stays inside one narrow Mobius/Warg lane so the first creator can get one real success before widening into bigger world packs, wider Mobius lanes, or deeper dev-side follow-through.

## Scope

Use this for:

- one first mentor-style guide NPC
- one first Warg-only Studio run
- one first pass through `preview -> save -> create -> proof -> publish`

Do not use it as the promise for:

- any game
- any host
- a bigger cast on the first try
- advanced family branching on the first try

## What You Will Make

- one mentor-style guide NPC
- one saved Warg project workspace
- one created first output
- one first publish decision backed by live proof when runtime is available, or an honest fallback when it is not

## Starter Path

- tutorial card: `First FPC in Warg`
- starter seed: `Mentor Guide`
- starter world: `Giran Mentor Desk`

## Before You Start

- open Studio and go to `Create`
- keep the current scope narrow: one guide NPC, one place, one first success
- if `GameServer` is listening, Studio can run the first live conversation test
- if runtime proof is unavailable, Studio still has an honest path through `Bundle To Publish` or `Stage For Dev Review`

## Step By Step

1. Open `Create` and find `First FPC in Warg`.
2. Click `Start Tutorial` or `Load First Warg Starter`.
3. Let Studio load `Mentor Guide -> Giran Mentor Desk`.
4. Click `Preview Exact Draft`.
5. Read the exact draft and confirm the guide feels useful, local, and human.
6. Click `Save Project`.
7. Click `Create My World Now`.
8. If live proof is available, click `Run First Conversation Test`.
9. If live proof is not available, use the honest fallback Studio offers:
   - `Bundle To Publish` when the safe runtime lane is still valid
   - `Stage For Dev Review` when the runtime lane is not ready for self-serve proof
10. Click `Save Publish Record`.
11. Open `World Library` to find the first tutorial FPC again.

## What Good First Success Looks Like

The first tutorial result does not need to feel perfect.

It should already feel:

- useful
- local to Warg
- a little human instead of robotic
- worth reopening in `Saved Projects` or `World Library`

It does not need to feel:

- like a finished premium cast
- like a full world pack
- like the final Dream Studio ceiling

## If The First Result Feels Too Polite

Stay inside the same narrow Warg lane and deepen it before widening scope:

- open `Warg Server-Life Tuning`
- open `Warg Scene + Continuity Follow-through`
- open `Return-Memory Anchors`
- keep the same guide and strengthen memory, gossip, flame handling, and setback talk

## What Not To Do On The First Run

- do not widen into a bigger cast yet
- do not switch to another game or host promise yet
- do not chase perfect lore depth before the first guide already feels real
- do not skip `Save Project`, because that is the easiest recovery point for a new creator

## After First Success

- reopen the same guide from `Saved Projects`
- reopen the same guide from `World Library`
- tune Warg memory, gossip, scene pressure, and continuity before you widen scope
- use `Copy Tutorial` or `Export Tutorial Markdown` if you want to hand the same narrow flow to another creator
- only move past this tutorial once one guide already feels believable
